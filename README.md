# FTP Sync Tool — Fluent

Утилита для Windows: синхронизация локальных и SMB-каталогов с FTP/FTPS-сервером.
Интерфейс в стиле Fluent, прогресс синхронизации, просмотр логов и сборка в один EXE.

Полностью обновлённый интерфейс в стиле выбранного варианта 02-Fluent:
светлый фон, синие акценты, цветные иконки, карточки состояния,
боковая навигация и отдельные разделы настроек. Интерфейс написан на
Tkinter/ttk; это оформление в стиле Fluent, без зависимости от WinUI.

## Что добавлено

- Разделы «Источник», «FTP-сервер», «Синхронизация», «Журнал».
- Карточки подключения, последнего запуска и результата текущего сеанса.
- Постоянная строка состояния и реальный прогресс по обработанным файлам.
- Фоновый поток операции: интерфейс остаётся отзывчивым.
- Проверка FTP/FTPS с закрытием соединения после проверки.
- Кнопка «Логи»: отдельное окно, автообновление раз в секунду,
  подсветка ошибок/предупреждений, копирование и открытие папки.
- Для больших журналов показываются последние 256 КБ; архивы ротации
  доступны через «Открыть папку».
- Пароли скрыты, рядом переключатель «Показать».
- Проверка числовых параметров перед сохранением.
- Ошибки загрузки и пропуск из-за другого экземпляра не выдаются за успех.
- Значок EXE в ICO с размерами 16, 24, 32, 48, 64, 128, 256.

## Быстрая настройка

Скопируйте `ftp_sync_config.example.ini` в `ftp_sync_config.ini` и заполните
свои параметры в интерфейсе. В примере удаление файлов на сервере отключено.
Личный INI с паролями, журналы и файлы состояния исключены через `.gitignore`.

## Запуск из исходников в Windows

Установите Python 3 с компонентом Tcl/Tk из официального установщика.
В папке комплекта откройте терминал:

```powershell
py -3 ftp_sync_tool.py
```

Сторонние библиотеки для запуска приложения не нужны.
Оставляйте `fluent_ui.py` и папку `assets` рядом со скриптом.

## Сборка EXE

1. Распакуйте весь комплект в отдельную папку на Windows.
2. Запустите `build_windows.bat`.
3. Скрипт создаст `.venv`, установит PyInstaller и соберёт
   `dist\ftp_sync_tool.exe`.
4. Для сохранения существующих настроек перенесите новый EXE в папку,
   где находится ваш `ftp_sync_config.ini`, предварительно закрыв старую версию.
   Сохраните также файл состояния `ftp_sync_state.json`.

Для установки PyInstaller нужен интернет. Иконки уже готовы; Pillow для
сборки EXE не требуется. EXE собирается именно на Windows. В этом комплекте
нового собранного EXE нет.

## Командная строка

```powershell
# Окно настроек
.\ftp_sync_tool.exe --gui
# Другая конфигурация в окне настроек
.\ftp_sync_tool.exe --gui --config C:\FTP\ftp_sync_config.ini
# Один проход без окна
.\ftp_sync_tool.exe --once --config C:\FTP\ftp_sync_config.ini
# Фоновая работа с режимом loop из INI
.\ftp_sync_tool.exe --config C:\FTP\ftp_sync_config.ini
```

Без аргументов открывается GUI. Кнопка «Синхронизировать» делает один
проход. Интервал и run_mode используются фоновым запуском через CLI;
GUI сам по таймеру синхронизацию не запускает. Сохранение параметров не
меняет уже запущенный отдельный CLI-процесс.

## Совместимость и поведение

Используется прежний формат INI. Конфигурация по умолчанию создаётся рядом
со скриптом/EXE. Относительные пути журнала и состояния вычисляются от
папки скрипта/EXE. При другом `--config` эта база остаётся той же.
Статистика последнего запуска относится к текущему сеансу GUI;
история сохраняется в журнале. Карточка подключения показывает результат
проверки либо состояние текущей операции, а не постоянный мониторинг FTP.

Правила зеркалирования исходного движка сохранены. Если включено
«Удалять на сервере файлы, отсутствующие в источнике», лишние файлы
удаляются. Синхронизацию желательно сначала проверить на тестовом каталоге.
При активной операции закрытие окна блокируется до её завершения.

## Проверки

```powershell
py -3 -m unittest -v test_fluent
```

Семь автономных тестов: валидация настроек, успешная загрузка и прогресс,
ошибка загрузки, недоступный источник, пропуск занятого запуска,
освобождение блокировки при исключении, повторное открытие журнала.
Дополнительная GUI-проверка проверяет подписи и ширину четырёх кнопок
окна журнала; без графического дисплея она пропускается.
Проверены синтаксис и автономные тесты в Linux. Визуальный запуск GUI и готового EXE
на Windows в этой среде не выполнялся.

## Файлы для разработчика

- `ftp_sync_tool.py` — движок синхронизации и CLI.
- `fluent_ui.py` — весь интерфейс.
- `ftp_sync_tool.spec` — однофайловая сборка PyInstaller с ресурсами.
- `build_windows.bat` — сборка на Windows.
- `assets/` — цветные иконки PNG и значок приложения ICO.
- `build_icons.py` — воспроизводимая генерация иконок; только для неё
  нужен Pillow (`py -3 -m pip install Pillow`).
- `test_fluent.py` — проверки без соединения с реальным FTP.

## Исправление кнопок журнала

Для кнопок без иконок явно используется текстовый режим (`compound="text"`),
а цвет подписей задан для обычного, активного и отключённого состояния.
Это устраняет пустые кнопки «Обновить», «Копировать», «Открыть папку» и
«Закрыть» в окне журнала на Windows. После получения обновлений пересоберите
EXE через `build_windows.bat`.

## Крупные чекбоксы

Все переключатели используют индикатор 22×22 пикселя при масштабе Windows
100%, с увеличением при высоком DPI. Рамка контрастная, выбранное состояние
синее с белой галочкой. Сохранены фокус с клавиатуры, переключение пробелом
и клик по подписи. Эти изменения действуют и в настройках, и в окне журнала.
